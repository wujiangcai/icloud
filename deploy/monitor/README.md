# Cloudflare R2 cost monitor

The server collects exact S3 object totals for both iCloud buckets every 15
minutes and supplements them with Cloudflare GraphQL operation metrics.

Copy `cloudflare-api.env.example` to the root-only path documented in
`../README.md`. Run `configure-cloudflare-budget-alert` once to create the
account-wide email alert; repeated runs are idempotent.

## Limits

- Cloudflare R2 Standard free storage: 10,000,000,000 bytes per month.
- Warning threshold: 7,000,000,000 bytes.
- Hard write threshold: 8,000,000,000 bytes.
- Class A warning/hard thresholds: 800,000 / 900,000 operations.
- Class B warning/hard thresholds: 8,000,000 / 9,000,000 operations.

The hard thresholds apply to this server's encrypted backups and to the mail
archive path when it is enabled. Local restic backups continue if an R2 write
is blocked. Cloudflare budget notifications are informational and do not cap
usage generated by unrelated services or credentials.

## Components

- Collector: `/usr/local/sbin/icloud-code-r2-monitor`
- Timer: `icloud-code-r2-monitor.timer`
- Secret-free snapshot: `data/platform/r2-monitor.json`
- Limits: `/etc/icloud-code-platform/r2-monitor.env`
- Cloudflare credentials: `/etc/icloud-code-platform/cloudflare-api.env`
- Operator dashboard: `/platform/operator`

Use `systemctl status icloud-code-r2-monitor.timer` and
`journalctl -u icloud-code-r2-monitor.service` to inspect collection status.
