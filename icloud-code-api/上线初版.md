# 上线初版

版本：`0.3.0`
发布名称：`上线初版`

## 公网入口

- 管理后台：<https://codes.nodelite.top/platform/operator>
- 客户接码页格式：`https://codes.nodelite.top/public/mail/{访问令牌}`

## 邮箱与接码地址导出

库存页面现在支持直接生成客户发货格式：

```text
邮箱----接码地址
```

例如：

```text
name@icloud.com----https://codes.nodelite.top/public/mail/pub_xxx
```

### 单个邮箱

1. 打开“邮箱库存”。
2. 找到目标邮箱，点击“发货”。
3. 在弹窗中点击“复制”，即可复制一行 `邮箱----接码地址`。

“发货”会复用现有有效链接；没有链接时会自动创建，不会重复生成。

### 批量邮箱

- **导出选中发货**：先勾选当前页邮箱，再点击批量栏的按钮，下载 `icloud-delivery-selected.txt`。
- **导出发货文本**：按照当前搜索、状态和 iCloud 账号筛选条件导出全部匹配邮箱，下载 `icloud-delivery.txt`。
- **导出库存 CSV**：继续导出库存管理字段，适合内部台账。

每行都是独立的 `邮箱----接码地址`，可以直接复制给客户或导入发货工具。

## 链接规则

- 新生成的接码令牌使用平台主密钥加密保存，重复导出会保持同一个链接。
- 旧版本已经存在、但无法恢复原始令牌的链接，第一次导出时会自动更新一次；之后会保持稳定。
- 点击“重置链接”会生成新地址，旧地址立即失效。
- 停用邮箱或停用客户不会导出可用接码地址。

## 已包含功能

- 多 iCloud 账号归类，同一账号可管理多个隐藏邮箱。
- Apple 隐藏邮箱同步、账号级 IMAP 同步和历史邮件记录。
- 库存、已卖出、自用会员、自用未开会员、停用、失效/垃圾等业务状态。
- 服务端分页、状态/账号/验证码筛选、批量改状态和 CSV 导出。
- 保留 new-icloud 的单批生成和按账号冷却时间执行的批量生成任务。
- Cloudflare R2 邮件归档及月度本地额度保护。
